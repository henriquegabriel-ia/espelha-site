# Espelha Site

Converte qualquer URL em dados JSON estruturados usando IA.

## Stack

- **Frontend:** Next.js App Router + shadcn/ui
- **IA:** OpenAI / Claude API (structured output)
- **Spec:** json-render (Vercel Labs)
- **Deploy:** Vercel

## Development

```bash
npm install
npm run dev
```
